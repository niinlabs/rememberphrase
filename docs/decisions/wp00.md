# WP00 — Safety and word-list decisions

**Status: Approved 2026-10-24.** These decisions define what Rememberphrase may build and claim. Changing one needs a new approved decision.

**Amended 2026-10-24:** D7 row 3 now requires a silent local check instead of a visible disposable sample, as part of the revised Prepare step. The green wording was also revised so the Airplane-mode limit reads as information, not an error.

**Amended 2026-10-25:** D5 now keeps step-3 edits when the count is raised; only lowering it warns first. D13 now includes a voluntary typing exercise in this tab; the earlier rule that the site never asks for the phrase to be typed back is superseded. D9 now states that the Capitalise, Add a number and Add a symbol controls keep the intact random-word count.

**Amended 2026-11-05:** D10 adds Nothing as a separator and allows 32 characters per random word in a joined token. D11 adds ten transition words. D12 lets any number of adjacent words join, split back into single words, and be removed. D13 adds an optional Check as I type and a clear button, and the practice result uses red and green with an icon. D7 adds row 1a: a deliberate, confirmed choice to continue while connected, which stays red and lasts for one phrase. D11 adds your own words, which never count as random, and "an"; connecting words are listed alphabetically.

**Amended 2026-11-17:** D11: connecting words and your own words are typed only if the user chooses (off by default); otherwise they are a memory aid, and the full story is shown under the phrase. D13 adds an optional hint that shows the connecting words with each random word masked.

**Amended 2026-11-18:** D8: a random word dressed up with capitals, look-alike swaps or added characters still counts as random, since it is no easier to guess; only a replaced word, or one with letters removed or split up, stops counting. The strength explanation is simplified to a dot count, the D4 guidance and one reason, with the rules under "What counts?"; the character count and the caveat are dropped. D13: practice becomes one card with four aids (Follow along, Reveal as you type, Connecting words, No aid by default), replacing Check as I type and Show connecting words; Reveal whole phrase stays as a separate control. Later the same day: the Check button is dropped; a match shows as soon as it is typed and offers Next attempt. Then Connecting words becomes a **Show connecting words** checkbox that adds them to Follow along or Reveal as you type, leaving three aids.

## D1 — Offline boundary

Version 1 works offline only in the tab that is already open. There is no offline reopening, service worker or downloadable copy. The interface tells users: "Keep this tab open. If you close or reload it, you will need to go online and start again."

**Why:** it is the only model consistent with storing nothing in the browser.

## D2 — Languages

Version 1 is English only, for both the interface and the word list. Other languages ship only once a reviewed word list and reviewed copy exist for them.

## D4 — Word count

Range 4–12, default 6. Guidance depends on the number of intact random words (D8):

| Intact random words | Guidance |
|---|---|
| 0–3 | "Too few random words for an important password." |
| 4–5 | "Shorter than we recommend for a master password or computer login." |
| 6 or more | "The length we recommend for a master password or computer login." |

**Why:** six matches EFF's recommendation; four words give roughly 2⁵² combinations against 2⁷⁷ for six. The guidance never says "secure".

## D5 — Changing the count with locked words

Raising the count adds new random words at the end, and after step-3 edits adds them to the end of the arranged phrase, keeping the edits. Lowering it removes unlocked words from the end; if that would remove a locked word, it stops and says "Unlock N words to go down to X words." Lowering the count after step-3 edits warns first.

## D6 — The "Confirming offline" check

- A request to `/reachability.txt` with a fresh query string, `cache: 'no-store'`, no credentials, no referrer and `redirect: 'manual'`, so redirects are never followed. It runs once after the user confirms Airplane mode, before any real phrase exists, and never during generation.
- **Any HTTP response is positive evidence of a connection and holds generation**, including a redirect, an error status or a Wi-Fi login page. The answer is decided when the response headers arrive.
- Only a network error or the **5-second timeout** is inconclusive, and never proof of being offline.
- **Skip** cancels a pending request and is recorded as skipped. A response that arrived before Skip still counts.
- The expected marker only selects the wording: "Rememberphrase answered, so you are still connected" or "A network answered (this can be a Wi-Fi login page). You may still be connected."

**Why:** any reply proves a working network path; a rare false warning is the safer mistake.

## D7 — Connection status table

Checked when the check finishes, on every Generate and Reroll, and on browser `online`/`offline` events. The first matching row wins. Implemented in `src/core/status.ts`.

| # | Condition | State | Real generation |
|---|---|---|---|
| 1 | Word list not ready, or secure random numbers unavailable | Amber | Held |
| 1a | The user chose to continue while connected (from row 2, confirmed) | Red: "You chose to continue while connected" | Allowed after the local check, for this phrase only |
| 2 | The check got any response, or the browser reported coming online after the user confirmed offline | Red | Held until the user confirms again and the check runs again, or chooses row 1a |
| 3 | Offline not confirmed, check not finished, or no successful local check | Amber | Held |
| 4 | Check skipped, or the browser still reports `navigator.onLine === true` | Amber, naming the reason | Allowed |
| 5 | Check failed or timed out, and the browser reports offline | Green: "You confirmed offline, and the word list is ready in this tab." with the note "Good to know: websites can't see your device's Airplane mode setting, so this relies on your own check." | Allowed |

**Row 4:** `navigator.onLine` often stays `true` in Airplane mode when a VPN or virtual network adapter exists. The copy says so: "Your browser still reports a network connection. This can be a VPN or virtual adapter; check that you're disconnected."  
**Row 3, local check:** once the user has confirmed offline and the check has ended without a response (including Skip), the tab silently draws a few words from the loaded list and discards them unseen. It is never displayed, logged, stored or sent, and makes no requests. Success shows the tab can make words; it is not evidence about the network. If it fails, preparation holds and the user can retry the check or confirm again. If the browser has no random source at all, confirming is disabled and the page explains why.  
**Row 2, red interruption:** any response, or a reconnection after confirmation, opens a red alert with an Acknowledge button. Acknowledging closes the alert only: the red hold stays, the confirmation is cleared, and the user must confirm again and run a new check.  
**Row 2 mid-session:** a phrase already on screen stays visible, and the site never claims it was transmitted.  
**Row 1a, continuing while connected (added 2026-11-05):** offered only while row 2 holds, as a secondary link ("I can't disconnect – continue while connected") under the red explanation in Go offline. A confirmation says the words are still made only in the tab and not sent by the page, but that while connected a tampered page or a browser extension could, and suggests a network that can be switched off; focus starts on "Go back and disconnect". After confirming, the silent local check runs and drawing is allowed, but the status stays red everywhere, never amber or green, and later reconnections do not interrupt. Clear phrase, starting over from the logo, or confirming offline again ends the choice, so a new phrase asks again.

## D8 — Strength explanation

- Count random words that still count: a draw counts while its word is in the text in one piece, ignoring capitals and allowing the familiar look-alike swaps and common leetspeak, some several characters long (for example `a`→`4` `@`, `b`→`8`, `e`→`3`, `g`→`9` `6`, `h`→`#` `|-|`, `m`→`|\/|`, `o`→`0` `()`, `s`→`5` `$`, `w`→`\/\/`; the full list is `LOOKALIKES` in `src/core/phrase.ts`), with anything added before or after it. A combined token counts each of its words found in order. A word that was replaced, lost letters or had characters put inside it no longer counts, and is labelled "Your own word". *(Amended 2026-11-18: previously any edit removed the credit. Dressing a word up does not make it easier to guess, because the attacker still has to find the drawn word.)*
- Show "How strong is this phrase?" in Remember: one dot per random draw in the phrase, filled while it counts, with the count in words ("6 random words" or "5 of 6 words still random"); the D4 guidance, whose caution mark for a short phrase shows at the top of Remember; and one reason naming the list size. The rules sit in a collapsed "What counts?". *(Amended 2026-11-18: the character count and the caveat "Based on how these words were generated…" are no longer shown.)*
- Connecting words, separators, substitutions, capitals, digits and symbols never change the guidance level.
- No bit counts, combination counts or crack times for the user's own phrase. No pattern-based estimator in version 1. If every word was rewritten: "We cannot estimate the strength of words you wrote yourself."

## D9 — Destination rules and decoration

- Default: "Requirements not specified."
- The user can state minimum and maximum length; required uppercase, lowercase, digit or symbol; spaces not allowed; and use at a start-up screen or on another keyboard layout (which warns about non-ASCII characters).
- Controls: Capitalise (first word or every word), Add a number, Add a symbol (the user picks which digit and symbol; both go at the end). They are applied on top of the words, so they keep the intact random-word count (D8) and Reset removes them. Other substitutions are suggested as tips and made by editing a word, which removes intact status as any edit does.
- The checklist reports only rules the user stated and never claims a service will accept the phrase.

## D10 — Separators and edit limits

- Separators: space (default), hyphen, period, underscore or nothing; one choice for the whole phrase. A combined token has no separator inside it.
- Each word: 1–32 characters for each random word it holds (a token joined from three words may have 96); no line breaks, tabs or control characters; no leading or trailing spaces; normalised to Unicode NFC. Non-ASCII characters are allowed but trigger the keyboard warning.

## D11 — Connecting words (English)

`a`, `after`, `an`, `and`, `at`, `before`, `but`, `by`, `for`, `from`, `in`, `into`, `near`, `of`, `on`, `or`, `over`, `so`, `the`, `then`, `to`, `under`, `with` (the original twelve plus eleven added on 2026-11-05, shown in alphabetical order). Each can be inserted any number of times, moved and removed. They are always shown differently from random words and never counted as random.

Since 2026-11-05 the user can also add **their own words**: free text under the same rules as an edited word (1–32 characters, no control characters or edge spaces), added at the end and then moved, edited or removed like a connector. They are labelled "Added by you", never count as random and do not change the guidance; Reset removes them. The preview itself stays read-only, so the page always knows which random words remain.

Since 2026-11-17, connecting words and your own words are left out of the typed phrase unless the user ticks "Include connecting words in the phrase" (off by default; Reset turns it off; it also covers your own words). While they are left out, the preview shows the full story "With connecting words" under the phrase, with the added words set apart. They never count as random, so the choice does not change the guidance or strength.

## D12 — Combining, splitting, reset and duplicates

- Combine joins two adjacent words, which may themselves be joins, up to the whole phrase; never connecting words, and not a join edited since joining. Every word keeps its draw identity and lock.
- Split separates a join back into its single words, and is available only while the joined text is unchanged; after an edit, "Reset my changes" restores the generated set.
- A word can be removed after a confirmation; its draws stop counting for the phrase, one word always stays, and Reset brings it back.
- Reset restores the latest generated set without new random draws; Back keeps the draft; Start fresh warns and draws a new set under the offline check.
- Duplicate words are allowed, with the note "This word appears twice. You can reroll it if you like." There is no strength adjustment.

## D13 — Practice and recovery

- Version 1 offers a voluntary typing exercise for the new phrase, in this tab only. It suggests a mental scene, a rhythm and recalling the phrase later. The reference phrase is hidden while practising and shown only on request. The practice field is masked by default, and an eye button shows or hides what was typed, without losing it or focus. A check compares the attempt exactly with the final phrase, including case, spaces, connecting words and symbols, and says match or mismatch without revealing the phrase. Practice can be retried and is never required; there is no separate skip button, because the recovery copy and Clear phrase are always on the page.
- Practice is not a login. It never asks for an existing password, recovery code or personal fact. No attempt or result is sent, logged or stored by the site. The attempt is cleared on retry, on leaving the step, when the phrase changes and on Clear phrase. Autofill and spellcheck settings are best efforts; the browser, operating system, extensions and people watching the screen are outside the site's control.
- Recovery: write the phrase on paper and keep it away from the device; never a photo, cloud note, chat message or file. For a password manager, also point to its own recovery or emergency-kit feature.
- Practice is one card with an aid selector, one aid at a time, **No aid** by default *(amended 2026-11-18; replaces Check as I type and the old Show connecting words)*:
  - **Follow along:** the whole phrase is shown faintly above the field and lights up while what is typed matches from the start; a mistake stops it, so it never lights the next character after one.
  - **Reveal as you type:** one dot per character, each replaced by the real character once it is typed correctly; a mistake stops it the same way.
  - **Show connecting words** (a checkbox, only when the phrase has connecting or own words; greyed out with No aid) adds them to the chosen aid: added words that are not typed are set apart where they sit, and in Reveal as you type the typed connecting words, separators and end decoration show in clear while each random word stays dots until typed. Screen readers hear each run of dots as its number of hidden characters.
  - **No aid:** nothing of the phrase is shown.
  - With Follow along and Reveal as you type, the result line also says as you go whether the typing is on track, too long or wrong. A match shows by itself in every mode, with **Next attempt** (or Enter) to start over; there is no Check button, and Enter on a wrong attempt says it doesn't match yet. Results use red and green with a tick or cross icon, so colour is never the only signal.
  - A separate **Reveal whole phrase** shows the phrase on request. The eye on the field only shows or hides what was typed. A clear button empties the field, and **Next attempt** clears it after a match.
- A "Clear phrase" button clears the phrase from the page. The site does not promise that every trace is erased.

## D14 — Threat model

- **In scope:** the phrase leaving the tab over the network; the site storing anything; misleading strength or safety claims; an attacker who knows the method and word list guessing the phrase.
- **Reduced, not eliminated:** tampered page delivery (strict Content Security Policy, first-party assets, pinned dependencies, public source); a connected device during generation (offline guidance and the D6 check).
- **Out of scope, stated in the interface:** a compromised device, malicious browser extensions, someone watching the screen, and what the browser or operating system keeps on its own.

## D15 — Tooling

Svelte 5, TypeScript, Vite, Vitest and Playwright. Each work package has a verifier, `scripts/verify-wpNN.mjs`, that prints PASS, FAIL or BLOCKED and exits non-zero unless everything passes. Attribution lives in `ATTRIBUTION.md` and in the interface.

## D16 — Deferred

Offline reopening or a downloadable copy; a second language; brand and trademark clearance (before public launch); a pattern-based strength estimator; Trusted Types enforcement; hosting provider.
